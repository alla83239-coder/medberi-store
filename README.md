# МёдБери — многостраничный прототип интернет-магазина

Витрина магазина натурального мёда, чая, свечей, продуктов пчеловодства и подарочных наборов.

## Страницы
- `MedBeri/index.html` — главная
- `MedBeri/catalog.html` — каталог с фильтрами, поиском и сортировкой
- `MedBeri/category.html?cat=Мёд` — отдельный экран категории
- `MedBeri/product.html?id=honey-flower` — карточка товара
- `MedBeri/favorites.html` — избранное
- `MedBeri/cart.html` — корзина
- `MedBeri/about.html` — о магазине
- `MedBeri/contacts.html` — контакты

## Технологии
HTML, CSS, JavaScript, Montserrat, SVG-иконки. Корзина и избранное сохраняются локально в браузере.

## Публикация
В настройках репозитория GitHub Pages выберите Deploy from a branch, ветку `main` и папку `/(root)`. Корневая `index.html` перенаправляет на `MedBeri/index.html`.

## Важно
Ассортимент, цены, описания, фотографии и контакты демонстрационные. Заказ, платежи, доставка и административная панель пока не подключены. Фотографии и шрифт загружаются из внешних источников и требуют интернета.
